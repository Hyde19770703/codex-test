# 幸福10 A2 樣品屋：奶油暖白設計草案

- `house-plan-designer.html`：下載後用桌面版 Chrome 或 Edge 開啟，可切換 2D、3D 與分屏。
- `house-plan-draft.zip`：含 HTML、戶型資料、2D／3D 圖片、設計假設與驗證說明。解壓縮後開啟裡面的 HTML。

這是依使用者提供的尺寸圖製作的草案，並非施工文件。層高暫設 2.8m，承重性及門窗高度待現場確認。原設計器拆牆功能存在房間標籤錯誤，請先避免使用；進階圖形功能未完成全部驗收。

HTML 使用 house-plan-designer 的 MIT 授權模板：https://github.com/ZWD11/house-plan-designer 。授權條款見 LICENSE-house-plan-designer.txt。
